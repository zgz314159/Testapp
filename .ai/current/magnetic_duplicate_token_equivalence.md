# 磁吸重建重复词块等价修复

日期：2026-07-29

## 问题

同一条文中出现两个文本完全相同的词块时，旧实现仍按唯一 token ID 和原始 order 判断位置。例如第7条中两处“电压等级。”视觉内容相同，但交换后不能通过检查，也不能正确点亮相邻关系。

## 修复

- 为词块增加去除空白后的等价键；
- 每次加入、撤回或移动后，对相同等价键的词块进行内部身份重绑定；
- 用户看到的词块内容、候选顺序和已摆放顺序不变；
- 唯一 ID 继续用于拖动、撤销、撤销栈和进度持久化；
- 恢复旧磁吸进度时同样执行重复词块身份重绑定；
- 不同文本即使语义相近也不能互换。

## 回归样本

“第7条 铁路交流电力系统……高压：1000V以上的电压等级。低压：1000V及其以下的电压等级。”中的两处“电压等级。”可互换；“高压：”与“低压：”仍不可互换。

## 影响边界

只修改磁吸重建内部词块身份匹配，不改变常规练习、考试、错题、收藏、历史、AI、原子题库数据、碎化设置和页面UI。
